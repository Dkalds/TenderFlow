# Guía de usuario de TenderFlow

TenderFlow es inteligencia de licitaciones TI del sector público español: lee
los anuncios oficiales (PLACSP, TED y las fuentes autonómicas activas), se
queda solo con los contratos tecnológicos y los convierte en una bandeja diaria
priorizada. Además da el contexto de mercado que hace falta para decidir una
oferta: dónde pujar, a qué precio y contra quién.

Esta guía explica, pantalla a pantalla, **para qué sirve cada parte de la
consola y cómo se usa**. Está escrita para quien trabaja con el producto, no
para quien lo desarrolla. Los recorridos de punta a punta y el test que
demuestra cada uno están en [casos-de-uso.md](../casos-de-uso.md).

Dos principios recorren todo el producto:

- **Cada cifra dice de dónde sale.** Cuando no hay datos suficientes, la
  pantalla lo dice («estimación», «parcial», «sin datos suficientes») en vez de
  inventar un número.
- **No da probabilidad de ganar**, y tampoco sustituye a la fuente oficial:
  enlaza a ella.

## Mantener esta guía

La guía describe el producto tal como es hoy, no como se piensa hacer. Si un
cambio en la consola renombra un botón, añade o retira una pantalla o cambia
quién puede hacer algo, el capítulo correspondiente se actualiza en el mismo
cambio.
